## Cómo instalar

```bash
# 1. Clonar el repositorio
git clone https://github.com/Cucholambr3ta/PROJ-ajicolor-ecommerce.git
cd PROJ-ajicolor-ecommerce

# 2. Instalar dependencias
npm install

# 3. Crear base de datos SQLite
npx prisma db push

# 4. (Opcional) Cargar datos iniciales
npx prisma db seed

# 5. Configurar variables de entorno
cp .env.example .env.local
# Editar .env.local con tus valores:
#   DATABASE_URL="file:./dev.db"
#   NEXTAUTH_URL="http://localhost:3000"
#   NEXTAUTH_SECRET="tu-secret-aqui"

# 6. Arrancar en desarrollo
npm run dev
```

La app estará disponible en `http://localhost:3000`.

## Known Issues

- **Login funcional pero sin seed de usuario:** Se requiere crear el usuario admin manualmente en la DB o agregar un script de seed que genere el usuario inicial con credenciales.
- **2FA TOTP no implementado aún:** La feature F06 está planificada para Sprint 5 (semanas 9-10).
- **Dashboard con KPIs estáticos:** Los datos del dashboard muestran valores de ejemplo hasta que se conecten las API routes con datos reales.
- **Webhook WhatsApp no configurado:** Requiere credenciales de Meta Cloud API en variables de entorno.
- **Upload de imágenes pendiente:** Vercel Blob o S3 no configurado. Los diseños usan URLs de ejemplo.
- **Pagos no integrados:** Stripe/Culqi pendiente de configuración.
- **Operaciones offline no implementadas:** PWA y localStorage buffer están en roadmap.
